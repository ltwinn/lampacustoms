# Lampa Customs

Комплексний плагін модифікацій для [Lampa](https://github.com/yumata/lampa-source).

## Встановлення

Lampa → **Налаштування** → **Розширення** → **Додати плагін**:

```text
https://ltwinn.github.io/lampacustoms/trailers.js
```
*(або `https://ltwinn.github.io/lampacustoms/customs.js`)*

У списку розширень плагін автоматично відображається з назвою **Lampa Customs** (замість «Без назви»).

---

## Можливості

### 1. Швидкий перегляд Filmix
На сторінці фільму під постером та кнопками додає горизонтальну стрічку з усіма доступними відеопотоками Filmix:
* **Озвучка / студія перекладу** (Дубляж, Цікава Ідея тощо).
* **Якість відео** (4K UHD, 1080p, 720p).
* **Орієнтовний розмір файлу** в ГБ (розраховується на основі бітрейту та тривалості фільму).
* **Миттєвий запуск** обраного варіанту в один клік пульта без необхідності заходити в загальне меню Online Mod.
* Працює на базі підключеного у вас `online_mod.js` (автоматично використовує збережений токен Filmix PRO та безпечні проксі).

### 2. Стрічка трейлерів
Горизонтальна стрічка трейлерів під верхнім блоком фільму / серіалу. 
* Мови: українська (типово), російська, англійська.
* Джерела: **TMDB** (основне) та **YouTube** (резерв, якщо в TMDB немає вибраною мовою).
* Можливість вказати власний YouTube Data API v3 ключ у налаштуваннях.

## Налаштування в Lampa

У бічному меню **Налаштування** з'являється єдиний розділ **«Lampa Customs»**:
* **Filmix (Швидкий перегляд):**
  * Увімкнути / вимкнути стрічку відео Filmix.
  * Показувати / приховувати орієнтовний розмір файлу.
* **Стрічка трейлерів:**
  * Увімкнути / вимкнути трейлери.
  * Вибір мов (Українська / Російська / Англійська).
  * Резервний пошук на YouTube та поле для API ключа.

## Локальна розробка та тестування

1. `./serve.sh`: локальний сервер з CORS без кешу, виведе адресу плагіна.
2. Вставити виведену адресу в налаштуваннях плагінів Lampa.
