# lampacustoms

Плагіни для [Lampa](https://github.com/yumata/lampa-source).

## Стрічка трейлерів (`trailers.js`)

**Встановлення:** Lampa → Налаштування → Розширення → Додати плагін →

```
https://ltwinn.github.io/lampacustoms/trailers.js
```

На сторінці фільму або серіалу під верхнім блоком (постер, кнопки), над «Подробно», з'являється горизонтальна
стрічка трейлерів. Мови вибираються в налаштуваннях: українська (типово), російська, англійська.
На картці — мітка мови (UA / RU / EN) і джерело (TMDB / YouTube). Трейлер відкривається у вбудованому програвачі Lampa,
як і її власні трейлери.

### Звідки трейлери
1. **TMDB**: трейлери й тизери вибраними мовами. Ключ не потрібен, використовується той самий доступ, що й у Lampa.
2. **YouTube** — лише резерв: якщо в TMDB немає нічого жодною з вибраних мов. Шукає «<назва цією мовою> <рік> трейлер українською /
   трейлер на русском / official trailer» і залишає лише відео, у назві яких є слово «трейлер/тизер» (trailer/teaser),
   значущі слова з назви фільму, а мова назви відповідає вибраній: для UA — літери і/ї/є/ґ або «укр/UA»,
   для RU — кирилиця без українських ознак, для EN — без кирилиці.
   Потрібен власний ключ YouTube Data API v3: Налаштування → «Стрічка трейлерів».
   Безкоштовна квота — близько 100 пошуків на добу, тому результати кешуються на тиждень. Кожна вибрана мова — окремий пошук.

Якщо трейлерів не знайдено, стрічка не з'являється.

### Як отримати ключ YouTube
[console.cloud.google.com](https://console.cloud.google.com) → створити проєкт → APIs & Services → Library →
«YouTube Data API v3» → Enable → Credentials → Create credentials → API key.
Бажано обмежити ключ лише YouTube Data API v3 (Edit API key → API restrictions).

## Розробка
1. `./serve.sh`: локальний сервер (CORS, без кешу), виведе адресу плагіна.
2. Lampa → Налаштування → Розширення → додати плагін → вставити адресу.

Сторінка Lampa працює через https, тож браузер заблокує плагін за адресою `http://<IP>`, але пропустить `http://localhost`.
